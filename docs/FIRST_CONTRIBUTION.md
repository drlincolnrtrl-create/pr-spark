# First contribution ideas

These intentionally small improvements are good places to begin:

1. Add a `--format json` output mode with tests.
2. Support `--body -` to read an issue body from standard input.
3. Add a `--version` flag based on `package.json`.
4. Improve the help text with a second realistic example.
5. Add tests for documentation, feature, and generic-improvement classification.

Before starting, comment on the issue so work is not duplicated. A good first PR changes one behavior, includes one focused test, and explains how it was verified.
