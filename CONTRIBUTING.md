# Contributing to PR Spark

Thanks for helping make open-source contribution planning less intimidating.

## A quick first contribution

1. Fork the repository and create a branch from `main`.
2. Choose an open issue, preferably one labelled `good first issue`.
3. Run `npm test` before making changes.
4. Make the smallest change that solves the issue.
5. Add or update a focused test for behavioral changes.
6. Open a pull request using the template.

## Development commands

```bash
npm test
node bin/pr-spark.js --title "Improve the empty state"
```

## Pull request expectations

- Explain the problem and the smallest useful change.
- Keep unrelated formatting and refactors out of the PR.
- Do not include credentials, private issue bodies, or personal data.
- Be kind and constructive in reviews.

If you are unsure where to start, open a discussion in an issue before writing code.
